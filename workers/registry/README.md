# KOV 등록 실시간 동기화

Discord Gateway를 계속 연결하는 읽기 전용 봇이다. 지정 등록 채널의 글 생성·수정·삭제와 반응 추가·제거를 Redis 대기열에 저장한다. 처리 시 Discord 원문과 반응 작성자의 현재 관리자 권한을 다시 확인한다. 공식 O `1077983354001035294`, X `1077983516144435360`을 사용한다. 봇이 메시지나 역할을 생성·삭제하지는 않는다.

## 실행 환경

- Node.js 24, 별도 npm 의존성 없음
- 환경변수: `KOV_REGISTRY_BOT_TOKEN`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`
- 선택 환경변수: `KOV_PREMIER_ACT` — Discord 신청서의 현재 액트 이름과 동일하게 입력한다. 비어 있으면 프리미어 내역에 현재 액트 확인 필요를 표시한다.
- Discord: 봇 서버 설치, 등록 채널 보기·메시지 기록 보기, Message Content Intent 활성화. Guild Members Intent는 요구하지 않는다.
- 로컬 실행: 프로젝트 루트에서 `npm run registry:worker`. 비밀값은 환경변수로 주입하고 저장소·로그에 기록하지 않는다.

`vercel.json`은 Vercel Daemon 1개, `iad1`, 메모리 `1Gi`를 설정한다. 데몬은 **Production 배포에서만 실행**하며 Preview에서는 코드·사이트를 검증한다. Production 환경에 기존 봇·Redis 환경변수가 있어야 한다. 배포가 바뀌면 기존 프로세스는 종료 신호를 받고 새 프로세스가 시작된다. `/health`는 내부 liveness 검사에만 사용한다.

Vercel Hobby의 월 한도는 Active CPU 5시간, Provisioned Memory 420GB-hour이다. 1Gi 인스턴스의 연속 실행은 약 420시간(17.5일)이며, 한도에 도달하면 다음 달 UTC 1일까지 정지된다. 한 달 내내 상시 운영하려면 유료 플랜 또는 별도 상시 호스트가 필요하다. 유료 전환은 코드 배포만으로 수행하지 않는다.

## 데이터 처리

정식 등록, 인원 추가·제외, 팀장 변경, 이름 변경, 해체, 팀↔GC 속성 변경, 30일 임시 등록, 프리미어 액트를 구분한다. 임시 등록은 만료되면 정식 목록에 섞이지 않는다. 기간 내 관리자 승인 인원 추가로 대표 포함 3명이 확인되거나 정식 등록이 승인되면 정식 목록으로 전환한다. 프리미어는 현재 액트 설정을 기준으로 구분한다.

계정·서버 가입 1주, 팀닉 통일, 최초 신청자·스탭 권한, 중복 등록, 신청 간격, 재등록 제한과 제재는 운영진의 판정 대상이다. 과거 승인 글만으로 모든 조건이나 무통보 역할 회수 사유를 재구성할 수 없으므로 사이트가 임의로 제재·역할 회수를 집행하지 않는다. 역할 회수와 같은 별도 운영 판정은 명시된 근거 없이 해체로 추정하지 않는다.

처리 중 프로세스가 종료돼도 작업은 Redis processing 목록에 남고 재시작 시 복구된다. 새 이벤트가 과거 이력 감사보다 먼저 처리된다. Gateway sequence는 이벤트가 Redis에 저장된 뒤에만 체크포인트한다. 정상 재연결은 Discord Resume를 사용하며, 새 세션에서는 최근 31일과 기존 승인 내역을 다시 검사한다. 처음 한 번은 전체 양식 이력도 보완한다. 대기열이 밀리거나 Discord 요청 제한에 걸리면 반영이 지연될 수 있다.

사이트는 15초 간격으로 공개 명단을 갱신하고 서버 캐시는 5초이다. 봇 heartbeat가 90초 이상 갱신되지 않으면 연결 대기로 표시한다. 원본 이벤트의 Discord 사용자 ID와 봇 토큰은 공개 API로 반환하지 않는다.
